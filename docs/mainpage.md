TOOBAD4ML {#mainpage}
=========

TOOBAD4ML is a tool for extracting features of Buffer Overflow
vulnerabilities written in C code in order to further analyze them
with Machine Learning techniques.

![TOOBAD4ML overview](assets/overview.png)

The tool is licensed under MIT, has been funded by the Addendum no. 4
to the Universidad de León-Instituto Nacional de Ciberseguridad
(INCIBE) Convention Framework on the "Detection of new threats and
unknown patterns" and was originally designed and developed by the
